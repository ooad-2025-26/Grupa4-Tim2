# OCULIS

OCULIS je ASP.NET Core MVC web aplikacija za upravljanje optikom, proizvodima, korisnicima i narudžbama.

## Funkcionalnosti

- Registracija i prijava korisnika
- Pregled i pretraga proizvoda
- Kreiranje online narudžbe i praćenje statusa
- Zakazivanje termina pregleda vida
- Automatski obračun popusta i pogodnosti
- Plaćanje narudžbi
- Elektronski karton korisnika
- Pregled lokacija poslovnica i kontakt informacija
- Slanje automatskih obavijesti korisnicima
